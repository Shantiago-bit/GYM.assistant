# Gym Assistant

Proyecto base fullstack TypeScript con Next.js, Tailwind y un motor de persistencia JSON.

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Vitest
- Framer Motion

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run type-check
npm run test
```
